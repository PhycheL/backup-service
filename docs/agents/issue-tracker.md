# Issue 跟踪器

本项目通过 GitHub Issues 跟踪规格和工作项，仓库为 `PhycheL/backup-service`。远程仓库已启用 Issues；通过 `gh` 命令行工具进行读取、发布和标签操作。

技能要求“发布到项目 Issue 跟踪器”时，应在这个仓库创建 GitHub Issue。发布前检查已有 Issues，避免重复创建；涉及多行正文时，从准备好的 Markdown 文件提交正文，保留实际换行。

本次 to-spec 使用用户明确指定的 `ready-for-agent` 标签，不额外进行分诊。标签词汇见 [标签说明](triage-labels.md)。

PR 作为请求入口：关闭。

该配置依据当前 Git 远程、GitHub 仓库状态和本次 to-spec 指令整理；如以后切换工作跟踪平台，应更新此说明。
