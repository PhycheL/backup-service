# 分诊标签

沿用技能的默认角色名称。本次 to-spec 明确要求使用 `ready-for-agent`；其余角色保留默认映射，只有实际使用时才需要核实或创建对应远程标签。

| 标准角色 | 项目标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 需要维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格已整理，可交由代理实施 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不安排实施 |

应用标签时使用对应名称；发布本次规格不需要先添加其他分诊标签。
