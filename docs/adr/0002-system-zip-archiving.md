# 调用 macOS 系统工具整体归档

用户已确认由 Python 3 负责配置、流程编排、备份包命名、保留处理与结果汇总，将整个源目录交给 macOS 系统自带的 zip 工具归档，并使用工具自身的递归归档和保留链接选项；符号链接归档与恢复属于完整文件夹备份的验收，不单独设功能或要求应用逐文件实现链接处理。这一决策取代架构决策 0001 中“由 Python 标准库生成 ZIP”的实现限定，以减少自行实现目录遍历和链接归档逻辑的工作；部署环境因此需要具备可用的系统压缩工具，仍无需第三方 Python 包。

ZIP 格式、普通文件内容和目录结构的恢复、保存符号链接本身、不跟随链接目标、不额外保存 macOS 特有属性，以及不保证同一时间点一致性的范围保持有效。已发布母规格保留原文，实施任务明确记录本次已确认的实现方式调整。
