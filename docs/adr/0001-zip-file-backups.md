# 使用 ZIP 保存文件级备份

压缩实现方式已由[架构决策 0002](0002-system-zip-archiving.md)更新；本决策中的恢复范围与一致性边界继续有效。

已决定以 Python 3 标准库生成 ZIP 备份包，恢复范围为普通文件内容、目录结构和符号链接，符号链接保存链接本身。为保持部署和运行方式简单，不额外保存 Finder 标签、资源叉等 macOS 特有属性，也不要求源目录暂停写入或进行文件变化检测，因此不承诺备份内容来自同一时间点。备份包会作为历史版本长期保留，后续若扩大恢复范围或增加时间点一致性保证，应重新评估归档格式、生成方式和既有备份包的恢复兼容性。
