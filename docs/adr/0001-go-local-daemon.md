# 用 Go 单二进制做本机常驻服务

这个仓库里已有工具是 Python 脚本，备份工具却要操作台随时可开、凌晨 3 点自己执行。决定做成一个 Go 单二进制：登录后由 LaunchAgent 拉起，进程内到点打归档，Go 模板提供只绑 `127.0.0.1` 的操作台，任务和日志放在 `~/Library/Application Support/` 的 SQLite 里，归档用 tar.gz。这样启动只需装一次代理、浏览器打开本机地址，不必依赖 venv 或 Node。

## Considered Options

- **Python 常驻 + venv**：和现有剪贴板工具一致，但「启动方便」会被解释器和虚拟环境拖住。
- **Node / 独立前端工程**：能做更花的操作台，会拆成两套工具链，和一个二进制冲突。
- **ditto zip**：Finder 更友好、更能保留 Mac 元数据；最终选 tar.gz，体积和通用性优先。
- **launchd 日历另起备份**：和常驻操作台抢同一任务的占用；计划时刻改由进程自己看表。
- **局域网可访问操作台**：远程方便，但操作台能改任务、触发备份且第一版无鉴权；只听本机。
