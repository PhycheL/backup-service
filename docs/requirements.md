# 文件夹备份需求

已整理为[完整规格](specs/folder-backup.md)，发布到 [GitHub Issue #1](https://github.com/PhycheL/backup-service/issues/1)，并标记 `ready-for-agent`。用户已确认以命令行入口进行整体行为测试。

## 已确认

- 调用后端程序时，将源目录压缩成备份包，存放到备份目录。
- 源目录和备份目录均可由后端程序直接访问。
- 程序采用一次性运行方式：每次启动执行备份，运行结束后退出。
- 不作为常驻服务运行，不通过持续监听 HTTP 请求或通知等待触发。
- 源目录和备份目录保存在配置文件中，程序启动时读取。
- 每次运行生成独立的新备份包，文件名包含时间戳，不覆盖已有备份包。
- 配置文件按备份项分别设置保留份数，例如最近 10 份；每个备份项的保留份数独立配置、独立计算。
- 仅在对应备份项的新备份成功后，按从旧到新的顺序清理该项超出保留份数的历史备份包；该项新备份失败时不清理其历史备份包。
- 不同备份项的备份包分别归属、分别清理，互不占用保留份数。
- 完整备份源目录中的所有内容，递归包含子目录、空目录和隐藏文件，不设置文件或目录排除规则。
- 符号链接保存链接本身，保留原有链接关系，不跟随链接读取或打包其指向的内容；链接指向源目录之外时，不额外打包外部内容。
- 直接读取并压缩源目录，不要求备份期间暂停写入，也不额外检测文件变化；备份内容以实际读取到的数据为准，不保证来自同一时间点。
- 文件读取或压缩发生错误时，本次备份判定为失败，不触发历史备份清理。
- 备份包采用 ZIP 格式。
- 首版运行平台为 macOS；不要求支持或验证其他操作系统，兼容其他平台不是验收条件。
- 实际部署在另一台 macOS，而非当前开发机器；目标机器的运行时安装情况尚未确认。
- 使用 Python 3 实现，以脚本方式运行。按后续任务拆分中已确认的调整，Python 负责配置读取、流程编排和历史备份清理，调用 macOS 系统自带的 zip 工具整体归档；无需第三方 Python 包，目标机器需要具备 Python 3 和可用的系统压缩工具。详见[架构决策 0002](adr/0002-system-zip-archiving.md)。
- 一份配置支持多个备份项，每项指定源目录和备份目录；程序按配置顺序逐项执行。
- 某个备份项失败时，继续执行后续备份项，最后统一汇总各项结果；只要有一项失败，程序就返回非零退出码。
- 同一台机器上已有该程序的实例正在运行时，新启动的实例提示“备份正在运行”，并以非零退出码立即退出，不等待已有实例完成。
- 不额外保存 Finder 标签、资源叉等 macOS 特有属性；恢复范围限定为普通文件内容、目录结构和符号链接。

## 建议的实现默认值

这些细节尚未逐项确认，在正式规格中同样标记为推荐默认值，保留其与已确认需求的区别。

1. 使用 JSON 配置，通过 `python3 backup.py --config /path/to/config.json` 指定配置文件。
2. 每个备份项设置唯一且稳定的 `name`，用于识别该项生成的备份包。`source` 和 `destination` 使用目标机器上的绝对路径，`keep` 为至少 1 的整数。更改 `name` 相当于新建备份项，原名称下的备份包不自动清理。
3. 备份包命名为 `<备份项名称>_<时间戳>_<防重名后缀>.zip`，包内保留源目录这一层目录。只清理能够识别为本程序为当前备份项生成的备份包，不删除备份目录中的其他文件。
4. 备份目录不存在时自动创建；源目录不存在或无法读取时，该项失败并继续下一项。备份目录不能等于任何已配置的源目录，也不能位于其内部，避免生成的备份包又进入待备份内容。
5. 压缩先写入临时文件，完整写入并成功关闭后才发布正式 ZIP，再进行该项的历史备份清理。失败的临时文件不计入保留份数；程序尽力移除本次失败产生的临时文件。
6. 清理旧包失败时保留已经完成的新备份，记录该项错误并继续后续项，最终返回非零退出码。配置整体无法解析或名称重复时直接报错退出。
7. 向终端输出各项的开始、结果、备份包路径和最终汇总；全部成功返回退出码 0，发生错误返回非零退出码。

## 推荐配置示例

以下是示例路径，部署时替换为目标 macOS 上的真实目录。两个备份项可以共用一个备份目录，其保留份数分别计算。

```json
{
  "backups": [
    {
      "name": "documents",
      "source": "/Users/backup/Documents",
      "destination": "/Volumes/Backup/archives",
      "keep": 10
    },
    {
      "name": "photos",
      "source": "/Users/backup/Pictures",
      "destination": "/Volumes/Backup/archives",
      "keep": 5
    }
  ]
}
```

## 验收场景

- 一次启动完成各项处理并退出，不保持监听。
- ZIP 包可恢复普通文件内容、子目录、空目录、隐藏文件和符号链接；不跟随符号链接打包目标内容。
- 每次生成新包且不覆盖旧包；同一备份项仅在新包成功后清理超额旧包。
- 多个备份项共用备份目录时，互不影响各自保留份数，不清理无关文件。
- 某项读取或压缩失败后保留其旧包，后续项继续执行，最终汇总失败并返回非零退出码。
- 已有实例运行时，第二个实例立即提示“备份正在运行”并以非零退出码退出。
- 不要求暂停源目录写入，不执行文件变化检测，不额外保存 macOS 特有属性。
