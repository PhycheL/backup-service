## 母规格

[规格：macOS 一次性多备份项 ZIP 备份程序](https://github.com/PhycheL/backup-service/issues/1)

## 要交付的行为

同一台 macOS 已有该程序实例运行时，新实例立即提示“备份正在运行”并以非零退出码退出。已有实例继续执行，结束后可再次正常启动，不需要操作者手动清理遗留的运行标志。

## 验收标准

- [ ] 单实例约束作用于同一台机器上的本程序，即使两个实例使用不同配置，也不能同时执行备份。
- [ ] 已有实例运行时，新实例立即输出“备份正在运行”并以非零退出码结束，不排队，不创建新 ZIP，不清理旧包，也不干扰第一个实例。
- [ ] 互斥覆盖整个命令生命周期，包含配置处理、全部备份项、已接入的旧包清理和结果汇总，直到程序结束。
- [ ] 正常完成、发生错误并退出或进程被终止后，互斥资源能够自动释放，后续启动无需人工删除残留标志；系统压缩子进程仍在执行时，不能因 Python 父进程结束就放行第二次备份。
- [ ] 此能力包围既有命令行运行流程即可，不要求以多项执行或历史清理实现完毕作为前置条件；后续接入的行为自动处于同一命令生命周期内。
- [ ] 通过真实子进程与可观察的运行进展或外部进程控制协调重叠场景，验证第二个实例的输出、退出码、无备份副作用，以及第一个实例结束后的再次启动；不使用固定等待时间作为并发正确性的依据。
- [ ] 更新重复启动提示、退出结果和异常结束后恢复运行的使用说明，不增加跨机器互斥或等待队列。
