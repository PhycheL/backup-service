## 母规格

[规格：macOS 一次性多备份项 ZIP 备份程序](https://github.com/PhycheL/backup-service/issues/1)

## 要交付的行为

操作者在 macOS 上启动 Python 3 命令行程序，读取一份仅包含一个备份项的配置，将整个源目录归档为带时间戳的新 ZIP，保存到备份目录，输出结果后退出。该票一次交付约定恢复范围内的完整备份，包含普通文件、隐藏内容、空目录和符号链接本身，并为后续多项运行和历史保留提供稳定的备份项归属。

沿用母规格建议的 JSON 配置、稳定名称、绝对目录路径和保留份数字段。本阶段验证保留份数是否合法，但不执行旧包清理；后续由历史保留任务实现该行为。符号链接作为完整文件夹归档的一项验收内容，不单独设任务或要求应用实现专用的链接处理模块。

已确认的实现方式：Python 负责配置与流程编排，将整个源目录交给 macOS 系统自带的 zip 工具，通过工具自身的递归归档和保留链接选项完成压缩，无需应用逐文件编写链接归档逻辑。这一决策取代母规格中“由 Python 标准库生成 ZIP”的实现限定，已记录为“调用 macOS 系统工具整体归档”的架构决策；母规格的恢复范围和其余行为约定仍然适用。

## 验收标准

- [ ] Python 3 程序调用 macOS 系统自带的 zip 工具整体压缩源目录，完成备份后结束进程，无需第三方 Python 包；部署说明明确 Python 和系统工具的运行前提，并检查工具是否可用。
- [ ] 可在启动时指定 JSON 配置，读取一个备份项的名称、源目录、备份目录和保留份数；保留份数为至少 1 的整数，错误配置给出清晰原因并非零退出。
- [ ] 此阶段对多项配置明确提示尚未支持并退出，不得只执行第一项后宣称全部成功；多项行为由后续任务扩展。
- [ ] ZIP 包内保留源目录这一层，包含所有普通文件、二进制内容、空文件、各层子目录、空目录及隐藏内容，中文和空格名称可正确恢复。
- [ ] 整体归档同时保存符号链接本身和原始目标字符串，涵盖相对、绝对、目录和断开链接；不遍历链接目标，不额外带入外部内容，循环链接不会引起递归遍历。
- [ ] 每次生成独立、带时间戳且能识别备份项归属的 ZIP；短时间内连续运行不覆盖已有包，也不删除历史备份或其他文件。
- [ ] 备份目录不存在时自动创建；源目录不存在、不可读取，或备份目录等于源目录或位于其内部时，明确失败且不把输出反复打包；路径别名也按实际目录关系处理。
- [ ] 先写临时产物，完整写入并成功关闭后才发布正式 ZIP。读取、压缩或写入错误不产生被认定为成功的正式备份，且尽力移除本次未完成产物。
- [ ] 对约定范围之外且无法归档的特殊文件系统对象明确报告该项失败，不静默遗漏后报告成功。符号链接属于受支持的归档内容。
- [ ] 输出开始、结果与成功备份包位置；成功返回 0，失败返回非零退出码。不增加源文件变化检测或 macOS 特有属性保存。
- [ ] 通过真实命令行、隔离临时目录和独立归档读取或解压验证上述行为，包括恢复普通内容和符号链接、连续运行、非法路径关系和失败时保留既有包；不以内部函数或调用次数作为验收接口。
- [ ] 交付可直接照做的配置、运行及经过验证的 macOS 解压说明；恢复验证同时检查文件内容、目录结构、链接类型和原始目标字符串，不只检查条目名称存在。

## 阻塞项

无，可立即开始。
