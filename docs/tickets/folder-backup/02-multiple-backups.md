## 母规格

[规格：macOS 一次性多备份项 ZIP 备份程序](https://github.com/PhycheL/backup-service/issues/1)

## 要交付的行为

操作者在一份配置中保存多个备份项，程序严格按配置顺序执行。某项失败后继续处理后续项，最终列出所有项目的结果；全部成功返回 0，任一项失败返回非零退出码。每项复用已经完成的整体归档能力，独立产生备份包，可共用一个备份目录。

## 验收标准

- [ ] 一次运行处理有序的多个备份项，每项具有独立且稳定的名称、源目录、备份目录和保留份数；多个项目可以使用同一个备份目录。
- [ ] 通过各项开始与结果等外部可观察信息确认执行顺序与配置顺序一致，不同时压缩多个备份项。
- [ ] 配置整体无法解析、字段结构不合法、名称重复或保留份数不合法时，在执行备份前明确报错并非零退出，避免将有歧义的配置部分执行。
- [ ] 在开始实际备份前，基于完整配置核对目录关系，使任一项的备份目录不能等于任一已配置源目录或位于其内部，包含路径别名。可归属到某项的目录或访问问题作为该项失败，其他合法项目继续执行。
- [ ] 中间备份项的源目录不存在、不可读取或发生实际归档错误时，该项报告失败；已成功的包保留，后续项仍尝试执行，失败项不发布正式成功包。
- [ ] 每项输出开始、结果、错误原因或成功备份包位置，最后汇总所有项目；全部成功返回 0，任意失败返回非零退出码，完成后结束进程。
- [ ] 本任务保持不清理历史包的既有行为，为后续历史保留任务提供逐项成功或失败的完整运行语义，不引入文件变化检测。
- [ ] 更新多备份项配置和结果说明；通过真实命令行验证多项成功、中间失败后继续、共用备份目录、跨项目录关系及非法全局配置，不绑定内部函数或遍历实现。
