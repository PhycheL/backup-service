# 03 — 多条任务、自定义计划时刻、已开始后不能改源或目标

**What to build:** 本机使用者新建任务时可以为该任务指定别的计划时刻；也可以同时存在多条任务，各用各的备份目标。已开始的任务不能改备份源或备份目标；要换源或换目标必须再新建一条，旧任务里的归档口径始终对应同一对目录。

**Blocked by:** 02 — 在操作台新建一条任务（源、目标、默认凌晨 3 点）

**Status:** ready-for-agent

- [ ] 新建时可以指定该任务自己的计划时刻，建成后列表显示的是指定的钟点而不是默认凌晨 3 点
- [ ] 可以同时存在多条任务，各自绑定自己的备份源和备份目标
- [ ] 各任务使用自己的备份目标，一条任务的信息不会写进另一条的备份目标
- [ ] 已开始的任务不能改备份源或备份目标
- [ ] 要换源或换目标必须再新建一条任务；旧任务的备份源和备份目标保持不变
- [ ] 操作台列表能同时展示这些任务
