# 07 — 走到各任务自己的计划时刻自动打归档

**What to build:** 进程开着时，每条未停用任务在自己的计划时刻开一轮自动打归档：该轮最多试 3 次、两次之间约 1 分钟；3 次都未成则该轮失败、不留半包、不占保留份数。下一次该任务的计划时刻重新给 3 次。每个本地日历日最多一轮。当天已经有计划归档后仍能再手动打一份。操作台可改已开始任务的计划时刻（源和目标仍不可改）：当天该轮尚未开始则改等新钟点；已开始或已结束则不再为新钟点开第二轮；不追溯已经过去的钟点，也不因改钟点立刻打。停用中的任务不到点打。多条任务按各自钟点触发，互不影响执行顺序。用注入的时间推进来验证。

**Blocked by:** 04 — 对未停用任务手动打出一份归档；05 — 停用、启用、删除任务且不碰已有归档

**Status:** ready-for-agent

- [ ] 每天在某条未停用任务的计划时刻自动尝试打一份归档
- [ ] 计划一轮最多试 3 次、两次之间约 1 分钟；3 次都未成则该轮失败、不写半包、不占保留份数
- [ ] 下一次该任务的计划时刻重新给 3 次尝试
- [ ] 每条未停用任务每个本地日历日最多一轮计划尝试
- [ ] 当天已经有计划归档后仍能再手动打一份
- [ ] 操作台可改已开始任务的计划时刻；备份源和备份目标仍不可改
- [ ] 若当天该轮尚未开始，改钟点后按新钟点等到点再开轮；不追溯已经过去的钟点，也不因改钟点立刻打归档
- [ ] 若当天该轮已开始或已结束，不再为新钟点开第二轮
- [ ] 停用中的任务不到自己的计划时刻打归档
- [ ] 多条任务按各自的计划时刻触发，互不影响执行顺序
- [ ] 用注入的时间推进来验证，而不是真的等到钟点
