# 08 — 进程当时不在则记漏次，起来不补打

**What to build:** 某条未停用任务在其计划时刻进程不在（机器未开或服务未起），记一次漏次并且不打归档。服务随后起来时可以为已经错过的日期补记漏次，但不得补打归档。开机或服务重新起来都不补做。漏次相对的是该任务当时配置的计划时刻。漏次不占保留份数。停用期间不记漏次。操作台日志能看到漏次。

**Blocked by:** 07 — 走到各任务自己的计划时刻自动打归档

**Status:** ready-for-agent

- [ ] 计划时刻当时进程不在，该未停用任务记一次漏次并且不打归档
- [ ] 服务随后起来时可以为已经错过的日期补记漏次，但不得补打归档
- [ ] 开机或服务重新起来时不补打归档
- [ ] 漏次相对的是该任务当时配置的计划时刻
- [ ] 漏次不占保留份数
- [ ] 停用期间即使到点也不记漏次
- [ ] 操作台能看到该任务的漏次日志
