# 05 — 停用、启用、删除任务且不碰已有归档

**What to build:** 本机使用者能停用一条任务，使它不再能手动备份，之后也不参加自己的计划时刻。可以再启用，从下一次自己的计划时刻起再自动打。可以删除一条任务，操作台上不再出现它，也不再自动或手动打。停用、启用、删除都不触碰备份目标里已有的归档；停用期间不记漏次。删除不等于清盘。

**Blocked by:** 04 — 对未停用任务手动打出一份归档

**Status:** ready-for-agent

- [ ] 停用后该任务不能再手动备份
- [ ] 重新启用后可以再次手动备份
- [ ] 删除后操作台不再列出该任务，也不能再对它自动或手动打归档
- [ ] 停用、启用、删除都不删除、不改写备份目标里已有的归档
- [ ] 停用期间不记漏次
- [ ] 已删除任务留下的归档继续留在原备份目标
