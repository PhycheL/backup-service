# 01 — 本机打开操作台，能看到空的任务列表

**What to build:** 本机使用者跑起服务后，用浏览器打开本机地址就能看到操作台；此时还没有任务，列表为空。操作台只听本机、不用登录。关掉再拉起服务，仍能打开操作台，列表仍为空，而不是每次都丢失存储或报错。任务和日志不写在任何备份目标里。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 服务起来后，本机浏览器打开操作台能看到任务列表，此时一条任务都没有
- [ ] 操作台只接受本机访问，不要求登录
- [ ] 关掉服务再拉起，操作台仍能打开，任务列表仍为空
- [ ] 任务和日志存在系统 Application Support 的存储里，备份目标目录不会因为「还没有任务」被写入任何文件
- [ ] 行为可通过备份应用的操作驱动验证（列出任务为零）；时钟与工作目录可注入
