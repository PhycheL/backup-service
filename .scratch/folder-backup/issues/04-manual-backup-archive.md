# 04 — 对未停用任务手动打出一份归档

**What to build:** 本机使用者能在操作台上对一条任务点一次手动备份，并立刻看到结果。成功则该任务的备份目标里多一份完整 tar.gz 归档，人自行用系统工具解开；操作台不做恢复、不写回备份源。手动备份只试 1 次。打出的就是归档。尝试开始前清掉该任务的半包；半包不是归档。同一任务同一时间只能有一份归档正在产生，后来者立即失败并写入日志、不排队。不同任务可以同时打。

**Blocked by:** 03 — 多条任务、自定义计划时刻、已开始后不能改源或目标

**Status:** ready-for-agent

- [ ] 对一条任务点一次手动备份，立刻能看到成功或失败
- [ ] 成功时备份目标里多一份完整 tar.gz 归档；任意一份都可以单独解开，不是增量链
- [ ] 手动备份只尝试 1 次，失败时不必等待重试
- [ ] 打出的就是归档，与之后的计划归档没有第二种包的区别
- [ ] 产生归档前先清掉该备份目标里属于半包的残文件；半包不计入保留份数
- [ ] 同一任务同一时间只能有一份归档正在产生；后到的手动立即失败并写入日志，不排队
- [ ] 不同任务可以同时打归档
- [ ] 操作台能看到该任务这次手动备份的成功或失败日志
- [ ] 失败不留下冒充归档的半包，不占保留份数；备份源不被写回
