# 02 — 在操作台新建一条任务（源、目标、默认凌晨 3 点）

**What to build:** 本机使用者能在操作台新建一条任务，指定备份源和备份目标；不填计划时刻则每天凌晨 3 点。备份源必须是已存在的文件夹，备份目标必须是已存在的完全空目录。任一不满足则任务不建立，并在操作台看见原因。建成后列表里能看到这条任务及其源、目标和计划时刻。本张还不打归档，也不做多条任务。

**Blocked by:** 01 — 本机打开操作台，能看到空的任务列表

**Status:** ready-for-agent

- [ ] 备份源是已存在的文件夹、备份目标是已存在的完全空目录时，任务创建成功，列表里能看到它的备份源、备份目标和计划时刻
- [ ] 新建时不填计划时刻，该任务的计划时刻为凌晨 3 点（机器本地时区）
- [ ] 备份源不存在或不是文件夹时，任务不建立，操作台能看见原因
- [ ] 备份目标不存在、不是目录、或里面已有任何文件或文件夹时，任务不建立，操作台能看见原因
- [ ] 创建失败后，列表里没有这条任务，备份源和备份目标都没有被改写
- [ ] 任务记录不写在备份目标目录里
